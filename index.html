Ingests high-frequency asset updates over REST and WebSockets with no dropped packets at peak load, and re-renders only the rows that change. Java 11, Spring Boot, React, PostgreSQL and Docker.

Product Multi-tenant analytics engine

How I work

Good backend work is mostly invisible. A request goes in, the pieces answer in order, and nothing on the screen moves until the data is right.

  1. 01Debug

    Read the failure before the guess.

    Start with the trace, the request and the last known good state. The theory comes after the evidence.

  2. 02Measure

    Instrument the slow path before changing it.

    See where the time and the writes actually go, then make the smallest change the numbers can defend.

  3. 03Maintain

    Leave the system quieter.

    Fewer moving parts, clearer boundaries and a handoff the next engineer can follow without a call.
